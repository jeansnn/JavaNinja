##  Sobre o Projeto

Este repositório serve como meu portfólio de lógica de programação e aplicação dos fundamentos da linguagem Java. Cada arquivo na pasta `src/` representa uma solução para um problema específico, cobrindo desde lógica básica até conceitos de orientação a objetos.

## Tecnologias Utilizadas
* **Java (JDK 17+)**
* **IntelliJ IDEA** (como IDE de desenvolvimento)
* **Git & GitHub** (para versionamento)

## Estrutura do Projeto

Todo o código-fonte está localizado na pasta `src/`. Os principais desafios estão em `src/Desafios`:

* `src/Desafios/CalculadoraDeBonus.java`: Implementação de lógica para cálculo de bônus de funcionários.
* `src/Desafios/ListadeTarefas.java`: Um sistema simples de CRUD (Criar, Ler, Atualizar, Deletar) para tarefas.
* `src/Desafios/RegistroDeTransacoes.java`: Simulação de registros de transações bancárias.
* `src/Desafios/ValidadordeContaBancaria.java`: Lógica para validação de formatos de conta bancária.
* `src/Desafios/TerminalDeCaixaEletronico.java`: Simulação de operações de um caixa eletrônico.
* *(...e muitos outros!)*

## Principais Aprendizados
* Aplicação de Estruturas Condicionais (if/else, switch) e de Repetição (for, while).
* Manipulação de Arrays e Coleções (Lists).
* Fundamentos da Programação Orientada a Objetos.
* Uso de Scanners para entrada de dados do usuário.
* Controle de versão com Git.
